# Enterprise Document Workspace (EDW)

Manage. Convert. Create. Collaborate. Secure.

## Technology Stack

- React + TypeScript
- Tailwind CSS
- NestJS + TypeScript
- PostgreSQL
- Prisma ORM
- pnpm Monorepo

## Applications

- apps/web: EDW Web Application
- apps/api: EDW Backend API
- packages/shared: Shared Types and Utilities
